# 원하는 타이포, 찾는 것부터 다듬는 것까지

데이터 리터러시 중간과제의 11장 웹 발표자료입니다. 기존 서비스 조사, 폰트 데이터 수집 결과, 향후 분석 계획을 담았습니다. 서비스 구현과 사용자 실험은 아직 진행하지 않았습니다.

## 발표

https://ancoded1234.github.io/typography-literacy-midterm/

좌우 방향키와 화면 버튼으로 이동하고, `F` 키 또는 전체화면 버튼으로 발표할 수 있습니다. `출처·범위`에서 데이터와 해석 조건을 볼 수 있습니다.

## 로컬 실행

저장소 폴더에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000/`을 엽니다.

## 공개 파일 범위

웹 발표에 필요한 HTML, CSS, JavaScript, 폰트·라이선스, 설명용 콘셉트 이미지와 발표에서 인용한 네 가지 서비스 조사 증거만 포함합니다. 원본 폰트 데이터, CSV, 수집 로그, 인증 정보, 개인 계정 정보는 포함하지 않습니다. 화면 캡처는 서비스명과 확인 시점을 발표 안에 표시합니다.

폰트 라이선스 전문과 anime.js MIT 라이선스는 각 `assets/` 하위에 보존했습니다. 폰트 표본 및 서비스 조사 결과의 범위와 한계는 발표의 출처 패널에 적었습니다.
