# 원하는 타이포, 찾는 것부터 다듬는 것까지

데이터 리터러시 중간고사: 주제 설명과 데이터 수집·분석 계획을 담은 9장 정적 HTML 발표입니다. 사용자 실험은 아직 수행하지 않았습니다.

Python으로 `python -m http.server 8000` 실행 후 브라우저에서 열 수 있습니다. 방향키·버튼·F 전체화면·출처 패널을 지원합니다.

공개판에는 직접 만든 도식만 사용하고 타 서비스의 수집 캡처는 포함하지 않습니다. 원본 수집 데이터·실험 로그·인증정보는 포함하지 않습니다.

서체는 Pretendard와 Gowun Batang/Gasoek One에서 필요한 글자만 포함하고 이름을 바꾼 Midterm Batang/Midterm Display입니다. 수정 글꼴의 저작권 고지와 원본 SIL OFL 1.1 전문은 assets/fonts에 보존했습니다. 실행 파일 전체의 일괄 라이선스를 부여하는 표시는 하지 않습니다.
