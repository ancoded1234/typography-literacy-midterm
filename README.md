# 원하는 타이포, 찾는 것부터 다듬는 것까지

데이터 리터러시 중간과제 웹 슬라이드입니다. 주제 설명, 공식 폰트 데이터 수집, 기존 서비스 조사 결과와 향후 분석 계획을 담은 11장 정적 HTML 발표자료입니다. 사용자 실험과 서비스 구현은 향후 계획이며 완료된 결과로 제시하지 않습니다.

## 공개 발표 URL

https://ancoded1234.github.io/typography-literacy-midterm/

## 로컬 실행

프로젝트 폴더에서 다음 명령을 실행한 뒤 브라우저에서 `http://localhost:8000/`을 엽니다.

```powershell
python -m http.server 8000
```

## 조작

- 좌우 방향키: 이전/다음 슬라이드
- 화면 아래 버튼: 슬라이드 이동
- 전체화면 버튼: 발표 모드
- 마지막 장의 출처 링크: 공식 자료 및 조사 서비스
