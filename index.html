02 / 실제 경험 → 폰트 탐색의 어려움

원하는 분위기의 폰트를 찾는 과정이 쉽지 않았다.

피그마(Figma) — 디자인 툴에서의 경험

  • 모바일 UI의 분위기에 맞는 폰트를 찾고 싶었다.
  • 피그마에서 여러 폰트를 하나씩 적용하며 비교했다.
  • 원하는 느낌의 폰트를 쉽게 찾기 어려웠다.
  • 무료 폰트를 더 찾아 외부 사이트를 살펴보기로 했다.
원하는 폰트를 찾지 못해
외부 사이트로 이동→

눈누(Noonnu) — 무료 글꼴 사이트에서의 경험

  • 무료 폰트를 찾으려고 눈누에서 추가로 탐색했다.
  • 폰트 이름이나 디자이너를 알면 찾기 쉬웠다.
  • 내가 알고 있던 건 이름이 아니라 ‘몽환적인 느낌’이었다.
  • 실제로 ‘몽환’을 검색했을 때 결과가 나오지 않았다.
디자인에 어울리는 폰트를 찾고 싶었지만, 피그마에서도 바로 찾기 어려웠고 눈누에서도 분위기만으로는 원하는 폰트를 찾기 쉽지 않았다.

STEP 03 · 증거 저장·비교

검색·기능 화면, 생성 PNG, 수정 전후 SVG, 서비스 비교 CSV와 보고서를 보관했다. 8곳 모두를 같은 깊이로 시험한 것은 아니다.

실제 조사에서 생긴 문제와 처리 방법
01 · 라이선스 원문 2개 누락

문제 표본 299개 중 원문 2개를 확보하지 못했다.

처리 누락으로 기록하고 전체 확보처럼 표시하지 않았다.

02 · 공식 태그와 사람의 느낌은 다를 수 있음

문제 태그가 ‘몽환적’·‘귀여운’ 같은 느낌과 맞는지 알 수 없었다.

처리 태그를 사용자 평가로 보지 않고, 향후 사람 평가로 확인하기로 했다.

03 · 사이트마다 검색 방법이 다름

문제 검색창·성격 조절·언어와 스타일 필터가 서로 달랐다.

처리 각 서비스의 방식을 직접 써 보고 기능과 결과를 나눠 기록했다.

04 · 이번 편집 파일 형식이 달랐음

문제 산돌구름은 PNG, Recraft는 SVG를 사용해 같은 조건의 편집 비교가 어려웠다.

처리 확인한 결과만 기록하고 우열은 판단하지 않았다. 같은 문구·과제로 비교할 예정이다.

PNG·SVG는 이번 조사에서 사용한 파일 형식이며, 서비스 전체 지원 형식의 판정이 아닙니다.직접 확인 · 공식 안내 · 미검증 구분
10 / 향후 분석 및 서비스 구축 방향

수집한 데이터를 바탕으로, 앞으로 어떤 서비스를 만들 수 있을까?

지금까지 수집한 폰트 정보와 기존 서비스 조사 결과를 활용해, 실제 디자이너에게 도움이 되는 타이포그래피 서비스를 구상하고자 한다.

폰트 데이터 분석→사용자 평가 및 서비스 비교→통합 서비스 구축 방향 검토
01사용 데이터 B + A

분위기 기반 폰트 추천 연구

공식 스타일 태그와 한국어 분위기 표현의 관계를 살피고, 사용자에게 후보의 분위기 적합성을 평가받는다. 한글 지원과 라이선스도 함께 고려한다.

추천 방식은 앞으로 연구·검증할 계획
02사용 데이터 C + 사용자 실험

기존 서비스의 사용 편의성 비교

같은 검색·편집 과제를 가능한 한 비슷한 조건으로 수행한다. 소요 시간, 조작 단계, 과제 완료 여부를 측정해 작업 흐름을 비교한다.

아직 시간·성공률·만족도를 측정하지 않음
03분석 결과 활용

통합 서비스 구축 방향 검토

조사 결과를 바탕으로 폰트 탐색부터 필요할 때의 AI 레터링 제작·부분 편집까지 잇는 시제품을 검토한다.

기존 서비스에도 일부 기능 연결 사례가 있음 · 편리함은 사용자 평가로 판단

최종 목표

폰트 이름을 몰라도 원하는 디자인 분위기에 맞는 타이포그래피를 쉽게 찾고, 필요할 때 자유롭게 다듬을 수 있는 작업 환경을 만드는 것.

자료 출처와 해석 범위

A·B 폰트 정보: Google Fonts 공식 저장소의 표본 299개를 사용했습니다. 296개 폰트에 공식 태그 20종이 연결됐고, 연결 기록은 3,306건입니다. 이 표본은 전체 폰트 시장을 대표하지 않습니다.

C 서비스 조사: 눈누, FontBrief, Adobe Fonts, Monotype Fonts, 산돌구름, Kittl, Recraft, Ideogram 8곳을 1차 조사했습니다. 슬라이드의 상세 사례는 직접 근거를 확보한 일부 기능만 보여줍니다. 미검증은 기능이 없다는 뜻이 아닙니다.

직접 확인한 핵심 사례: 눈누 검색 화면·FontBrief 스타일 필터·산돌구름 생성 PNG·Recraft SVG 편집. Recraft의 286개 경로는 이번에 내려받은 한 파일의 구조이며 일반적인 결과를 보장하지 않습니다. 검색 적합성, 사용성, 사용자 만족도는 측정하지 않았습니다.

분석 계획: 분위기 평가, 검색 과제, 부분 수정 과제는 앞으로 수행할 연구입니다. 참여자 실험 결과는 아직 없습니다. 통합 서비스도 구상 단계이며 기존 도구 조합과 편리함을 비교할 계획입니다.
